# Firefly provenance and materials

Original 970-vertex anatomical firefly OBJ by Lauriane Gelebart / The Colorless Journey; source [GitHub](https://github.com/LaurianeGelebart/The_Colorless_Journey/tree/main/assets/models), repository LICENSE CC0 1.0. Original OBJ and MTL are retained unchanged; local MTL refers to missing upstream image paths, so upgrade_animation.py uses a temporary *name-only* MTL to import original per-face material indexes and then replaces every Blender slot with a valid material. Supplied source wing and head image maps are retained, packed and used. The 92 modeled fireflies instance the original insect mesh at positions baked from Blender Newton particle physics, not 92 static emissive spheres. Original yellow/black texture maps were upstream Git LFS pointer-only blobs; they were *not* downloaded or substituted with false textures. The abdomen is emissive and the other original mesh parts retain distinct materials, but insect readability at distant camera scale remains unverified.
